# English Translation Glossary — பெரிய இடத்துப் பெண்

This glossary records recurring English decisions for the derived translation layer. It does **not** authorize any change to canonical Tamil. If a translation problem raises doubt about Tamil wording, return to the canonical page/source audit first.

## Work title and names

| Tamil | English | Policy |
|---|---|---|
| `பெரிய இடத்துப் பெண்` | **The Woman of the Great House** | working English reading title; Tamil remains authoritative |
| `உலகநாதர்` | **Ulaganathar** | stable character form |
| `உலகநாத முதலியார்` | **Ulaganatha Mudaliar** | retain `Mudaliar` when explicitly printed |
| `கண்ணம்மா` | **Kannamma** | default character form |
| `கண்ணம்மாள்` | **Kannammal** | retain where the source form is locally visible/meaningful |
| `வீரன்` | **Veeran** | proper name, never translate as “hero” |
| `உத்தண்டி` | **Uthandi** | stable character form |
| `குமுதா` | **Kumudha** | preserve source form |
| `குமுதம்` | **Kumudam** | preserve distinction; source explicitly says `குமுதா` is a shortened form |

## Kinship and household/status language

| Tamil | Current English handling | Note |
|---|---|---|
| `அத்தான்` | **Aththan** | retain on first/important uses; in this work Veeran is Kumudha's cross-cousin and prospective husband |
| `அண்ணி` | **Anni** when the household-address form matters | in Uthandi's account `நம் வீட்டு அண்ணி` refers to Kannamma; do not force a literal sister-in-law relation into English |
| `எஜமான்` | **master / employer** | choose by employment/household context; Uthandi's deferential direct address uses “Master” |
| `எஜமானி / எஜமானியம்மாள்` | **lady of the house / female employer** | avoid misleading modern sexual sense of “mistress” |
| `சீமான்` | **wealthy gentleman / man of means** | preserve class register without inventing a formal title |
| `பணக்காரர்` | **rich man / wealthy household** | contextual |
| `மண்டிக்கடை` | **Mandi Shop** | retained in pilot satire `King of the Mandi Shop`; do not assign a narrower institution unsupported by source |
| `தலையாரி` | **talaiyari** | retained because the exact historical office/function should not be over-specified; context establishes Uthandi as an estate worker/functionary |
| `பண்ணையாள்` | **estate labourer** | functional class description supported by local context |
| `குடியானவன்` | **cultivator** | do not import a more precise tenancy status without source evidence |
| `குடித்தனக்காரி` | **good housewife** | source-period household ideal in Ulaganathar's speech; do not present as narrator-endorsed universal norm |
| `பாட்டாளி` | **labourer** | preserves class register |

## Source-sensitive readings

These are English-side decisions only; exact Tamil remains preserved in canonical records.

### Batch 1 / pilot

- `இதயப் படுதா` — **“the curtain of his heart.”**
- `சங்கார` in `சாகும்போது என்ன சங்கார வேண்டியிருக்கு!` — **“Why all this ceremony when we're going to die!”** as a cautious local rendering.
- `விவகார தாட்சண்யமாக` — **“an affair of discretion.”**
- `வீரனத்திக்கு முக்காட வைத்தன` — **“put a veil over Veeran's daring.”**
- `மாதிரி பார்க்கக்கூட இல்லை` — **“was not even much to look at”** after pilot context review; Tamil unchanged.
- `கொவ்வை இதழ்கள்` — **“kovvai-fruit lips.”**

### Batch 2 / Uthandi

- `அடிவயிற்றில் 'பசீர்' என்கிறது` — **“his lower belly is forever going ‘paseer’”**; preserve the printed onomatopoeic surface instead of inventing a normalized Tamil reading.
- `சப்பைக்கட்டுகள் கட்டினேன்` — **“patching together hollow reassurances”** in Uthandi's retrospective self-blame.
- `இந்த கபோதியிடம் காசு ஏது?` — **“where would a poor wretch like me get the money?”**; preserve the self-deprecating force without over-specifying lexical history.
- `கண்கள் செக்கச் செவேலென்றேதோன்றின` — **“Her eyes looked a vivid raw red.”**
- `பாழும் கடவுள் / பாழும் தெய்வங்கள்` — **wretched God / wretched gods**, preserving Uthandi's anger rather than softening it.

## Style lock through Batch 2

- source satire and abrupt exclamations remain visible in English;
- unusual source metaphors are not silently domesticated;
- source dots/ellipses are retained where they carry voice or an apparent textual gap;
- one Tamil paragraph normally maps to one English paragraph;
- canonical page joins remain traceable through HTML comments;
- no narrator is corrected using information revealed by a later narrator;
- class/debt language is translated from the current speaker's perspective rather than turned into external historical commentary;
- source household kinship-address forms may be retained where a literal English kinship label would mislead.

Add new glossary entries only when a recurring translation decision is actually encountered and source-supported.
