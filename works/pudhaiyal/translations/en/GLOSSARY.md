# Translation glossary — புதையல்

This is a controlled translation glossary. It never changes canonical Tamil.

| Tamil | English handling | Reason / status |
|---|---|---|
| `புதையல்` | **Treasure** | working English title |
| `மனோரா` | **Manora** | preserve source-facing place/monument name and its own derivation discussion |
| `மருங்கப் பள்ளம் / மருங்கப்பள்ளம்` | **Marungappallam** | stable transliteration; Tamil spacing variation remains in source |
| `பொன் குட்டம்` | **pon-kuttam** | retain; source explains it, no external mineral identification imposed |
| `கம்மாளர்` | **Kammalar** | retain uncertainty because the introduction itself asks whether it means only goldsmiths |
| `பாண்டு` | **pandu** | historical ailment term; no modern diagnosis inferred |
| `அம்பலம்` | context-sensitive; often retain title/name relationship | do not flatten a source social/title usage prematurely |

Add recurring names, titles and terms only after source-checked translation establishes the need.
