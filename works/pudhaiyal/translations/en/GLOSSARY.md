# Translation glossary — புதையல்

This is a controlled translation glossary. It never changes canonical Tamil.

| Tamil | English handling | Reason / status |
|---|---|---|
| `புதையல்` | **Treasure** | working English title |
| `மனோரா` | **Manora** | preserve source-facing place/monument name and its own derivation discussion |
| `மருங்கப் பள்ளம் / மருங்கப்பள்ளம்` | **Marungappallam** | stable transliteration; Tamil spacing variation remains in source |
| `புதுப்பட்டினம்` | **Puduppattinam** | stable place-name transliteration |
| `ராஜா மடம் / ராஜாமடம்` | **Raja Madam** | stable English place-name handling across Part 006 while Tamil source spacing/form remains untouched |
| `துக்காராம்` | **Dukkaram** | stable character-name transliteration used in Parts 002–003 |
| `பொன் குட்டம்` | **pon-kuttam** | retain; source explains it, no external mineral identification imposed |
| `குளிசக் கல்` | **kulisakkal** | retain conservatively; do not impose an external mineral/scientific identification |
| `கம்மாளர்` | **Kammalar** | retain uncertainty because the introduction itself asks whether it means only goldsmiths |
| `பாண்டு` | **pandu** | historical ailment term; no modern diagnosis inferred |
| `அம்பலம்` | context-sensitive; often retain title/name relationship | do not flatten a source social/title usage prematurely |
| `கங்காணி` | **kangani** | plantation labour-supervision term; translate surrounding function contextually without replacing the Tamil authority |
| `காக்துரை` | **Kaakdurai** | source character/proprietor name; no outside historical identification asserted |
| `டாக்துரை` | **Dog Durai** | source-internal wordplay/name used by workers; treat as narrative wordplay, not an independently verified historical label |
| `சமாராதனை` | **samaaraadhanai** where needed | retain culture-specific religious/feeding context rather than over-specifying |
| `சக்கிலிய` | **Chakkili** | retain the source's caste-marked/insulting wording in chapter 29 rather than flattening it to the occupational label “cobbler”; the surrounding sandal joke remains in context |
| `நளபாக` | **nalabagam** | retain the source culinary expression; chapter 32 uses it in Raman's boast without requiring an external explanatory substitution |
| `திருக்கைவால்` | **thirukkai-vaal whip** | Part 007 torture passage; conservative transliteration avoids imposing an external zoological identification on the Tamil term |
| `ரச வல்லி` | **rasa-valli** | Part 007 supplied lexical form is source-specific/uncertain; retain rather than inventing a more specific label for the woman Durai suspects was sent to entice him |
| `குடுகுடுப்பைக்காரன்` | **kudukuduppai fortune-teller** | preserve the source-facing occupational/cultural term while making the narrative role readable in English |
| `குடுகுடுப்பாண்டி` | **Kudukuduppandi** | retain Ambalam's colloquial direct address to the fortune-teller rather than flattening it into a speaker label |
| `சாயபு` | **Saibu** | retain the fortune-teller's repeated self-reference/title in the Part-007 dialogue |
| `சண்டாளன்` | **Chandalan** | retain the source's caste-marked/insulting wording in Chapter 39 rather than replacing it with a neutral generic insult |

Add recurring names, titles and terms only after source-checked translation establishes the need.
