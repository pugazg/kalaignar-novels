## Structural correction after full read

The earlier manifest incorrectly described scans 4–7 as a complete textual unit followed by a separate `ராயசம் வெங்கண்ணு` unit. Full-source review shows continuous narrative architecture instead:

1. **Scans 4–7:** opening polemical frame around the `பலிபீடம்` metaphor.
2. **Scan 7:** the narrator explicitly introduces Venganna as a film-like lesson — `திரைப் படமாக உருப்பெற்றிருக்கிறார்... படக்காட்சி ஆரம்பமாகிறது... படம் உங்களுக்கு ஒரு பாடம் தரட்டும்.`
3. **Scans 8–29:** embedded cinematic-historical dramatization headed `ராயசம் வெங்கண்ணு — தஞ்சை சரித்திரக் கதை`.
4. **Scan 30:** `படம் முடிந்துவிட்டது. பாடம் கற்றுக்கொண்டீர்களா? பலிபீடம் நோக்க...` — explicit return from the internal film to the main argument.
5. **Scans 31–33:** concluding direct address, ending the same `பலிபீடம் நோக்கி` work.

Accordingly, every body page now uses one continuous `balipeedam-nokki` filename sequence. `ராயசம் வெங்கண்ணு` remains only an internal section label preserving the printed title card.
